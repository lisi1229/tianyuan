# 天元修仙记 · 云海疑云

《天元修仙记》第一章改编的互动文字游戏。单文件网页，无依赖、无后端、断网可玩。

**在线玩**：https://lisi1229.github.io/tianyuan/

## 结构

- `index.html` —— 全部内容：样式、剧情节点、存档逻辑都在这一个文件里

## 怎么改

剧情在 `index.html` 里的 `NODES` 对象中，每个节点长这样：

```js
节点名:{
  t:["第一段","第二段"],          // 正文段落
  fx:{"道心":-5,"线索":1},        // 进入该节点时结算的属性变化
  c:[["选项文字","目标节点"], ...]  // 选项
}
```

结局节点用 `end:"结局名"` 代替 `c`。

属性只有三个：`道心`、`灵力`、`线索`，取值 0–100。
